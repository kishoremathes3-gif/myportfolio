Case Study

Iris Garden

Dog Daycare Management Ecosystem (Italy)

Role WordPress & UI/UX Developer
Client Location Italy (International Project)
Development Stack WordPress, Google Antigravity, PHP, JS

Project Overview

Iris Garden is a premium dog daycare center based in Italy. The goal of this project was to transition their business from manual bookings to a fully automated management platform. The ecosystem comprises user-facing web pages, a customer booking portal, a secure authentication workflow, automatic custom-styled email templates, and a powerful back-office management console for the admin staff.

WordPress Page Design

Designed and built highly interactive, mobile-first public pages in WordPress. Focused on clean layouts, warm typography, and clear calls-to-action that capture client interest and guide them directly into the daycare booking engine.

Authentication Module

Engineered a secure registration and login system. Dog owners can securely create accounts, save profiles for multiple pets (including medical records and vaccination details), and access their customer portals seamlessly.

Custom Mail Templates

Designed and developed automated, responsive HTML email templates triggered by system events (e.g., successful bookings, appointment approvals, vaccination expiration reminders). This streamlined communication between the daycare and dog owners.

AI-First Dev

Customer & Admin Dashboards

Developed the complete frontend interfaces (all pages) for both the Customer and Admin dashboards. Built within Google's Antigravity AI-first development tool, guaranteeing pixel-perfect alignment and extreme fluid interactivity.

  • Customer Portal: Dynamic booking scheduling, pet profiles manager, interactive calendar, and transaction receipts.
  • Admin Dashboard: Visual scheduler grid, daycare capacity tracking, pet status updates, automated logs, and staff control panel.
