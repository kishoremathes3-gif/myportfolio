Case Study

Iris Garden

Dog Daycare Management Ecosystem (Italy)

Role WordPress Developer
Client Location Italy (International Project)
Development Stack WordPress, Google Antigravity, PHP, JS

01. Overview

Iris Garden is a live dog daycare booking platform developed for an Italy-based client. The platform enables pet owners to book daycare services online, manage their pet profiles, track appointments, and interact with the daycare facility through a streamlined digital experience.

My role involved WordPress customization, booking flow configuration, dashboard page customisation, and collaboration with a senior developer.

02. Problem

The client was managing daycare appointments manually, which created challenges in booking management, customer communication, and pet record tracking.

Key challenges:
  • Manual appointment scheduling
  • No centralized customer dashboard
  • Difficulty managing pet information
  • Time-consuming administrative processes
  • Lack of an online booking experience

03. Requirements

The client needed a platform that could:

  • Allow customers to book daycare services online
  • Store pet information and profiles
  • Provide appointment management functionality
  • Enable administrators to manage bookings efficiently
  • Deliver a mobile-friendly experience
  • Support future scalability

04. Research

Before designing the platform, I studied:

  • Existing pet daycare and pet boarding websites
  • User booking behavior for service-based businesses
  • Dashboard layouts and patterns
  • Mobile-first booking experiences
  • Appointment scheduling workflows

The goal was to reduce friction and make the booking process simple for pet owners.

05. Wireframes

Created low-fidelity wireframes for:

  • Homepage
  • Booking Flow
  • Customer Dashboard
  • Pet Profile Management
  • Appointment Management
  • Admin Dashboard Structure

These wireframes helped define the user journey before moving into visual design.

06. Final Design

The final interface focused on:

  • Clean and modern layouts
  • Easy navigation
  • Mobile responsiveness
  • Simplified booking process
  • User-friendly dashboard experience
  • Clear call-to-actions

Special attention was given to ensuring that users could complete bookings with minimal steps.

07. Development

Platform Stack

  • WordPress
  • Custom Booking Functionality
  • Dashboard Customization
  • Responsive Web Design

Development Highlights

  • Implemented customer booking workflows
  • Customized dashboard experiences
  • Configured booking management features
  • Integrated customer and pet information systems
  • Optimized responsive layouts for mobile devices

Development was completed using an AI-assisted workflow in collaboration with a senior developer.

08. Result

Achievements:

  • Successfully launched a live production website
  • Enabled online daycare booking functionality
  • Reduced manual appointment handling
  • Improved customer convenience
  • Streamlined administration workflows
  • Delivered a scalable platform for future growth

The platform is currently being used by real customers and supports day-to-day business operations.
